# Custom PCB Breakout (`hardware/pcb/`)

This directory contains design files (Gerber files and KiCad project files) for custom breakout boards:
- **Fightstick Interconnect Hat**: An Arduino UNO-compatible shield that routes Sanwa quick-disconnect terminals directly to STM32 GPIO pins with ESD protection.
- **Haptic & LED Power Hat**: Includes onboard 5V boost regulator, MOSFET gate driver, and reverse-EMF flyback diode for high-torque vibration feedback.
