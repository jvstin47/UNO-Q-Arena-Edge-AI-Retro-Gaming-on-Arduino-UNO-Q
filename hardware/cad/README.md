# CAD & 3D Print Mounts (`hardware/cad/`)

This directory contains STEP and STL files for 3D printing and laser cutting:
- `enclosure/`: Laser-cutter DXF vector cutouts for 3mm acrylic or birch plywood arcade fightstick enclosures.
- `joystick-mount/`: Mounting bracket adapters for Sanwa JLF joysticks.
- `oled-mount/`: Snap-in panel-mount bezel for 0.96" SSD1306 OLED displays.
- `board-cradle/`: Shock-absorbent mounting cradle for the Arduino UNO Q board.
