# Hardware Suppliers & Sourcing Guide

Recommended component sources for reproducing the **UNO Q Arena** hardware build:

| Component | Recommended Vendors | Notes |
| :--- | :--- | :--- |
| **Arduino UNO Q** | Arduino Store, Mouser, DigiKey | Ensure official model with QRB2210 + STM32 |
| **Arcade Controls (Sanwa)** | FocusAttack, Paradise Arcade, ArcadeShock | Genuine Sanwa JLF joysticks and OBSF buttons recommended for lowest contact bounce |
| **I2C OLED (SSD1306)** | Adafruit, SparkFun, AliExpress | 0.96" or 1.3" 128x64 display (I2C address 0x3C) |
| **WS2812B NeoPixel** | Adafruit NeoPixel Stick, Waveshare | 8-pixel 5050 RGB LED strip |
| **Haptic Motor & Driver** | Adafruit DRV2605L, SparkFun Haptic Motor | Or discrete N-channel MOSFET circuit with flyback diode |
| **Potentiometer** | Bourns, Alpha, Mouser | 10k Ohm linear taper panel mount |
| **Acrylic Fightstick Case** | Eternal Arcade, AllFightSticks, Ponoko | 3mm acrylic or MDF laser-cut template |
